# apc-propeller
Aerodynamic Performance Evaluation of an APC Propeller in ANSYS Fluent

Simulated 3D incompressible flow over an APC propeller in ANSYS Fluent using an ICEM CFD structured hexahedral mesh and the k-omega SST turbulence model.

Monitored thrust, drag, and torque, extracting pressure coefficient (C_p) distributions via ANSYS CFD-Post and Tecplot 360 EX to validate performance against experimental data.
